# Digital VLSI SoC Design using OpenLANE


This repository contains my notes, practical work, screenshots, assignments, and learning outcomes from the **Digital VLSI SoC Design and Planning Workshop** using the **OpenLANE ASIC Flow** and **Sky130 Process Design Kit (PDK)**.

The objective of this repository is to document my learning journey and maintain all workshop-related resources in a structured manner.

# Workshop Overview

This workshop focuses on the complete **RTL-to-GDSII ASIC Design Flow** using open-source Electronic Design Automation (EDA) tools. It covers both theoretical concepts and practical implementation, helping learners understand how a digital circuit is transformed into a manufacturable integrated circuit.

# Learning Objectives

Throughout this workshop, I aim to:

- Understand the fundamentals of VLSI and ASIC Design.
- Learn the complete RTL-to-GDSII design flow.
- Gain hands-on experience with OpenLANE.
- Understand the Sky130 Process Design Kit.
- Explore synthesis, floorplanning, placement, CTS, routing, and physical verification.
- Learn to visualize layouts using Magic.
- Build a strong foundation in open-source ASIC design.
