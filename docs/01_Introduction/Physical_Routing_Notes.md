# Routing

## Routing Overview
- Connect all placed standard cells.
- Routing is performed after CTS.

## Routing Stages
1. Global Routing (FastRoute)
2. Detailed Routing (TritonRoute)

## Maze Routing (Lee Algorithm)
- Finds a valid path between source and destination.
- Expands search until destination is reached.
- Retraces the shortest path.

## DRC Clean Routing
- Final routing must satisfy all design rules.
- Removes spacing and width violations.
# TritonRoute (Detailed Routing)

## Purpose
- Performs detailed routing.
- Uses guides generated by FastRoute.

## Preprocessed Route Guides
- Split guides
- Merge guides
- Bridge guides
- Optimize routing paths

## Panel Routing
- Intra-layer parallel routing
- Inter-layer sequential routing

## Connectivity
- Uses Access Points (APs)
- Connects pins and metal layers correctly.

## Routing Topology
- Optimizes routing paths.
- Uses graph-based routing algorithms.
# Parasitic Extraction

## Purpose
- Extract resistance (R) and capacitance (C) from routed layout.
- Generate parasitic information for timing analysis.

## Power Distribution Network (PDN)
- Creates power rings.
- Creates power straps.
- Connects VDD and GND.
- Delivers power uniformly across the chip.

## Final Verification
- Extract parasitics.
- Re-run timing analysis.
- Check setup and hold timing.
- Ensure DRC-clean routed design.
